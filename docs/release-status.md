# 发布与验证状态

核验日期：2026-10-20（Asia/Shanghai）。

## 已上线

- 支付域名与 HTTPS：`https://paywc.bornforthis.cn`，Cloudflare Pages 自定义域名状态为 active，经 Service binding 转发到 `brclio-wechatpay` Worker。
- 管理入口：`https://paywc.bornforthis.cn/admin`。已验证登录、会话、加密配置读写、产品登记、独立凭据、密钥轮换、Skill 导出。
- 当前线上为 live 模式，仅开放 Native。仓库默认仍是 demo/关闭；维护线上版本使用 `npm run deploy:live`，普通 `npm run deploy` 会发布演示/关闭配置。
- 订单、工作索引和产品配置仅使用指定 GitHub 私有数据仓库，并以 AES-256-GCM 加密。Cloudflare 保存运行密钥；不使用 D1、KV、R2、Durable Objects 或消息队列保存业务记录。
- 原支付宝域名 `pay.bornforthis.cn` 与原支付宝项目未修改。

## 已实际验证

1. 真实微信 API 签名请求与微信公钥响应验签。通过查询不存在的订单确认商户密钥与公钥的请求/应答互通。
2. 真实 Native 预下单：人民币 1 分，返回有效微信付款二维码；重复业务订单返回同一中心订单，受保护收银台查询成功。
3. 查询确认 NOTPAY，主动关单后再次查询确认 CLOSED，并已将本地加密订单同步为 CLOSED。没有付款、没有扣款、没有发放权益。
4. 登录后复制自动接入 Skill，不附带管理员会话，仅用复制包里的 Bearer 授权自动登记产品、获取该产品业务密钥和详细 Skill、更新商品、保留其他 SKU。
5. 跨产品访问拒绝；管理员暂停状态保留；轮换产品密钥后临时授权撤销；导出不包含 GitHub Token、商户私钥或管理员会话密钥。
6. 部署验收用产品配置已清理；关闭的 Native 验收订单保留在私有加密账本供审计，不是假造的已付款订单。
7. 103 项自动测试通过，TypeScript、浏览器脚本语法、Worker 打包和部署预检通过。另以真实 workerd 验证 fetch 接收者及手动重定向兼容性；以隔离业务夹具验证保留支付宝、SQLite 原子开通和并发去重。两种生成的 Skill 均通过格式校验。

## 权限与接入边界

自动接入 Skill 提供 24 小时单产品配置授权。AI 可在该范围登记/修改回调地址、返回来源、已开放渠道及商品价格，取得该产品的业务密钥。它不能更改其他产品、商户全局配置或管理员暂停状态，不能退款或读取商户底层密钥。

目标 AI 必须已经能操作目标项目的代码；GitHub、Cloudflare 等部署访问依照目标环境原有授权。Skill 不会自动提供这些第三方账号权限。已使用本支付中心的项目应复制对应产品卡片的专属 Skill，避免建立另一套中心产品配置。
